# Nova Tasks

A futuristic, glassmorphism-inspired To-Do List web app built with HTML, CSS, and JavaScript.

Nova Tasks keeps task management simple while making the experience feel premium, modern, and interactive with animated task cards, smooth transitions, productivity widgets, and a responsive dark UI.

## Features

- Add tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- Reset the full task list in one click
- Task counter and live progress tracking
- Task sorting and filtering
- Search tasks instantly
- Expandable task details
- Priority badges and status indicators
- Custom animated modals and toast notifications
- Responsive design for desktop, tablet, and mobile

## Design Highlights

- Dark futuristic theme
- Glassmorphism + soft neumorphism styling
- Keyboard-inspired controls and task cards
- Animated progress ring
- Floating ambient particles and glow effects
- Smooth hover, completion, and delete animations
- Collapsible creator section in the footer

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
